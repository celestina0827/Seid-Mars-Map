## 🌌 1. Cross-Galaxy Design Inspiration
*This project fulfills the NASA Space Apps design specification by drawing structural and GIS inspiration from non-Mars missions and agency telemetry systems.*

> **"Our HUD UI design is heavily inspired by NASA's Earth Observing System Data and Information System (EOSDIS) dashboards and the Artemis Moon mission telemetry layouts, adapted for a high-contrast Martian environment."**

While our interface adopts an immersive, high-contrast tactical aesthetic, its core data architecture and telemetry hierarchy are firmly rooted in real aerospace engineering:
* **Earth EOSDIS Parallels**: Our environmental matrix and multi-dimensional threat radars mirror NASA's Earth Observing System Data and Information System (EOSDIS) multi-layered panels, optimized for real-time atmospheric pressure, wind shear, and dust opacity ($\tau$) tracking.
* **Artemis Moon Mission Telemetry**: The live electrocardiogram (ECG), depleting oxygen reserve tanks ($O_2$), and EVA suit biometrics layouts directly emulate the environmental control and life support systems (ECLSS) monitoring standards used in the Artemis lunar missions.

## 🛠️ 2. Core Features & Architecture
The **SEID Mars App** is engineered as a zero-setup, high-performance browser-based mission control system utilizing vanilla web technologies and advanced data visualization libraries:

* **🧭 3D Interactive Mars Globe & Pathfinding**
  * Built on Plotly.js orthographic projections integrated with USGS landmarks and NASA Trek CTX/MOLA satellite tiles.
  * Computes and renders real Curiosity rover traverses across Gale Crater and Mount Sharp waypoints.
* **📊 Tactical Route & Threat Scanner**
  * Features neon-glow Chart.js elevation profiles and multi-axis threat radar evaluations (Radiation, Dust, Terrain, Cold, Gear).
* **🩺 Biometric & Psychological Monitor**
  * Real-time synthetic PQRST ECG waveform telemetry synchronized with active mission checkpoints.
  * Integrated PSS-12 Martian crew psychological stress evaluator that automatically triggers **EVA Stand-down Safety Locks** when stress thresholds exceed critical limits.
* **🚨 Random Emergency Incident System**
  * Simulates extreme Martian environmental hazards (e.g., perchlorate dust seal failures, steep slope slips) coupled with actionable Tactical Action Sequences.
* **📖 Field Survival Codex & Glossary**
  * Instant search and indexing for specialized Martian terminology (*Regolith, ISRU, Sabatier, Rodwell*)
